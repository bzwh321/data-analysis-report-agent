# 结论优先级规则

## 排序原则
1. 影响规模大 × 紧迫度高 → 第一位
2. 影响规模大 × 紧迫度低（慢性风险） → 第二位
3. 影响规模中 × 紧迫度高 → 第三位
4. 影响规模小 / 结构健康 → 末位或不列入Summary

## 具体规则
- 利润率跌破critical_low（10%） → 无论规模大小，必须排第一
- 总量平稳但内部结构漂移 → 列为慢性风险，放第二位，标注预警时间线
- 单次事件导致的指标波动（如促销季） → 降优先级，说明可剔除后的真实水平
- 增速高但利润率健康 → 正面信号，放结论末尾

## 禁止的结论形式
- 禁止"需要关注" → 必须说"建议在X时间内做Y决策"
- 禁止把事件性冲击当结构性问题 → 归因后必须区分
- 禁止等权排列所有发现 → 必须有明确的第一优先级
