# Report Writing Micro Prompt

冷静、克制、客观。证据链留在内部，报告只写完整的话。每句话先交代必要的对象、时间、比较和数字，再自然落到一个最短结论；下一个独立结论按阅读顺序递进。能在计划行宽内稳定放进一行的，用一句一行表达；放不进一行且继续压缩会损失信息的，拆成分点。不要外显“证据、结论、边界、判断”等答题标签，也不要外显“以下结论只使用验证链数据”“不延伸为判断建议”等写作治理说明。涉及季节性、促销、渠道、价格、销量、结构或成本等原因时，必须先完成驱动因素拆解验证，不能从时间共现直接命名原因。每句话必须新增数据、判断、业务含义、已授权策略或必要限制；删掉不损失信息的句子就删。不要使用教学式串场、空洞承接、夸张标题或未经验证的常识。缺素材时返回验证问题，不要补写。
