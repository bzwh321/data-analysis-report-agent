Use the `consulting-board-memo` page design style.

Design the report like a board-ready consulting memo, not a dashboard. Use a publication layout: strong letterhead, narrow readable prose, thin horizontal rules, a recommendation box near the top, and a wide option matrix. The first screen must answer the decision question and make the recommended path visually unmistakable.

Use dark text on a white page. Use a Bain-like red only as a small identity/accent mark, and use muted teal only for the recommended path. Keep colors sparse; most structure should come from typography, rules, indentation, and table hierarchy. The page should feel reviewed by a consulting partner, not assembled from generic cards.

Every recommendation must include why now, the tradeoff, the condition under which it changes, and evidence references. Put risks close to the recommendation. Use full-sentence figure titles when tables or charts appear. Move ordinary data range, metric formulas, source lists, and chart notes to a concise end-notes section unless the note affects the recommendation.

Use report-native labels in the report language. For Chinese reports, avoid generic English labels such as "Recommendation", "Situation", "Complication", or "Figure"; use concise Chinese equivalents or remove the label if the heading already carries the meaning. Do not use equal-width three-card summaries as the default ending; use a risk register, evidence appendix, decision record, or option matrix instead.

Do not use KPI tiles, decorative badges, gradient hero blocks, rounded card grids, or dashboard chrome. Do not bury the recommendation after a long background section.
